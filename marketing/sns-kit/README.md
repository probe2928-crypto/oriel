## ⚠️ 계정·브라우저 규칙 (2026-11-26 확정)
- Instagram @orielfoundation 게시는 **Claude in Chrome**(mcp__claude-in-chrome__*)에서 한다. Chrome 인스타는 @orielfoundation으로 로그인돼 있음.
- 내장 브라우저(Claude_Browser) 인스타는 **@lifejunjun(여행 사업) 계정** — 오리엘 게시에 쓰지 말고, 계정 전환·로그아웃도 하지 않는다.
- 게시 전 화면 왼쪽 프로필이 orielfoundation인지 꼭 확인. 아니면 건너뛰고 기록.
- Facebook Oriel 페이지도 Chrome('지금 전환'으로 Oriel 페이지로 행동).

## Instagram @orielfoundation — "눈으로 보는 이야기"
- 형식: 캐러셀 3~7장(4:5, 1080×1350)이 기본. 1장 = 훅(질문·한 문장·숫자), 마지막 장 = 행동 유도("프로필 링크에서 신청", "저장해두세요").
- 캡션: 첫 줄 125자 안에 핵심(더보기 전에 보이는 부분). 본문은 짧은 줄바꿈, 이모지 1~3개. 영어 → 한국어 2~3줄.
- 해시태그 5~10개(#volunteer #Philippines #education #childrenfirst #OrielFoundation #해외봉사 #필리핀봉사 등 섞어서).
- 톤: 따뜻하고 개인적. "우리"가 말한다.

## LinkedIn (회사 페이지 + 세준 개인 퍼가기) — "일하는 사람의 시선"
- 형식: 글 위주 + 이미지 1장 또는 PDF/문서 캐러셀. 1,000~1,500자.
- 구조: 첫 2줄 훅(의외의 사실/배운 점) → 짧은 문단 3~5개 → 숫자·목록 → 질문으로 끝내기("여러분 회사는 어떻게 봉사하나요?").
- 주제: 재단을 어떻게 만드는지(거버넌스·투명성·파트너 고르는 법), 직장인·전문가가 도울 수 있는 방법, 배운 점.
- 해시태그 3~5개. 이모지 최소. 링크는 본문 끝에 1개.
- 세준 개인 계정 퍼가기: 1인칭, 1~3문장, 솔직한 한마디("재단 만들면서 제일 어려운 건…").

## Facebook Oriel Foundation 페이지 — "가족·지인에게 전하는 소식"
- 형식: 사진 1~3장 + 중간 길이 글(300~600자). 링크 바로 넣어도 됨(UTM 포함).
- 톤: 편지처럼 다정하게. 한국어 비중을 인스타보다 크게(한국어 먼저도 OK). 질문으로 댓글 유도.
- 해시태그 0~3개.

## Telegram @oriel_foundation — "가장 먼저 듣는 공지"
- 형식: 짧은 공지 3~6줄, 굵은 첫 줄, 이모지 머리표(🪟 📅 👉), 링크 1개. 가로 이미지(1200×675) 또는 이미지 없이.
- 내용: 봉사 일정·신청·새 글 소식처럼 "알아야 할 것" 위주. 한/영 같이.

- 해시태그 1~2개. 가로 이미지.
